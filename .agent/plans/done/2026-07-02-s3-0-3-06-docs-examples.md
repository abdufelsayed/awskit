## Acceptance Criteria

- README examples pass raw strings for buckets, keys, regions, owners, content
  types, header values, pagination markers/bounds, upload ids, part numbers,
  endpoint URLs, and signing regions where they are request inputs.
- Package `.mld` guides explain that public request inputs are string-facing and
  domain types still exist for response facts, internal validation, and advanced
  support APIs.
- Request options are shown through `options` or `options_exn` builders.
- Presign examples use `Presigned.*.options` or `options_exn`, not record
  update from `default_options`.
- Transfer, listing, multipart resume, presign upload-part, expected owner,
  content/header value, and integer request-input examples use the new
  string/int-facing builders.
- Endpoint examples pass endpoint and signing region strings to
  `Endpoint_config` constructors.
- No public docs/examples mention `Object.Delete_many` except the 0.3 changelog
  in plan 07.
- Presigned URL docs continue to distinguish safe logging accessors from
  `reveal_url`.
