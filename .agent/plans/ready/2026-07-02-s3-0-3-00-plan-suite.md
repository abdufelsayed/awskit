## Shared Rules

- Public request inputs are primitive strings/ints.
- Validated domain types remain internal and in response/result models.
- Public option construction goes through builders returning `result`, with
  deliberate `_exn` bridges.
- Request option records may be inspectable but not freely constructible or
  updatable by users.
- Public helpers added to `.mli` files are supported API. Add only semantic,
  operation-owned helpers that are reasonable for users too.
- No compatibility aliases or deprecation bridges for old public S3 APIs.
